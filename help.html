Help & Common Questions

Simple answers to get you moving quickly.

Go to User Dashboard → choose a dataset → state your purpose → submit. You’ll see your request tracked as pending/approved/denied.

Check your User Dashboard. Once approved, you can view/download the dataset from View Data. All access is automatically logged with a timestamp and stated purpose.

The audit log records who accessed what, when, and why. Only Admins can view/export the full log from History.

If a file can’t be found, the app shows a clear error. Contact an Admin to re-upload the dataset or add inline content.

Use plain language. Example: “Quarterly KPI report for Finance, no redistribution.” Avoid sensitive details in the purpose text.
